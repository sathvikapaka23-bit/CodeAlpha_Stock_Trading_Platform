# Stock Trading Platform

## CodeAlpha Java Programming Internship

### Task 2: Stock Trading Platform

This project is a simple console-based Stock Trading Platform developed using Java as part of the CodeAlpha Java Programming Internship.

The application simulates basic stock market activities such as viewing stocks, buying stocks, selling stocks, and managing a user's portfolio.

## Features

- Display available stocks and their prices
- Buy stocks
- Sell stocks
- View current portfolio
- View available balance
- Track the quantity of stocks owned
- Validate user input
- Prevent purchases when the balance is insufficient
- Prevent selling more stocks than owned
- Simple menu-driven interface

## Technologies Used

- Java
- Object-Oriented Programming (OOP)
- ArrayList
- Scanner
- Loops
- Conditional Statements
- Methods
